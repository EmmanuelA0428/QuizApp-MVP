# QuizApp 🎯  

## Overview  
QuizApp is a **Java-based** quiz application that runs on a **local SQL Server database**. It was built as a **learning project** to improve my skills in:  
- **Java programming** (Object-Oriented Design)  
- **SQL Server database management**  
- **Connecting Java to SQL using JDBC**  
- **Structuring applications for scalability**  

This project serves as **practice** for a much larger and more complex application I plan to build in the future.  

---

## 🚀 Technologies Used  
- **Java** (Core Java, OOP principles)  
- **SQL Server** (Database management)  
- **JDBC** (Java Database Connectivity)  

---

## 🛠 How It Works  
- The user answers a series of questions stored in an **SQL Server database**.  
- Each response is recorded and compared against correct answers.  
- Scores are calculated, and feedback is provided.  

---

## 🎯 Key Lessons Learned  
- How to **design a relational database** and interact with it using SQL.  
- How to use **JDBC to connect Java applications** to an SQL database.  
- How to **structure a Java project** for clarity and maintainability.  

---

## 🔥 How This Prepares Me for Future Projects  
This project is a stepping stone for **a much larger, scalable application** where:  
- The database will handle **more complex data relationships**.  
- The Java application will implement **authentication, user profiles, and analytics**.  
- The UI will be improved for **better user experience** (potentially with JavaFX or a web front-end).  

This small project allowed me to **experiment, debug, and refine my understanding** before tackling bigger challenges.  

---

## 📌 Future Improvements  
In the next phase, I plan to:  
- **Expand the question bank** to cover more topics.  
- **Improve the UI** for a better user experience.  
- **Implement user authentication** and tracking progress over multiple sessions.
